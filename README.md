# ИИ-агент колл-центра: банкротство физических лиц

Виртуальный менеджер КЦ: квалифицирует клиента по регламенту, отвечает на вопросы
и страхи, «продаёт» компанию и записывает подходящего лида на живую консультацию юриста.

## Как устроен
- **Системный промпт** — только роль, тон, этапы и жёсткие правила. Плюс служебный блок
  «собрано / не собрано», который обновляется после каждого `save_info`.
- **Скилы** (`skills/*.md`) — расширенная информация по 29 темам регламента; агент тянет
  их тулом `get_skill` только когда тема всплыла в диалоге.
- **Тулы**: `save_info` (слоты клиента), `get_skill` (тема регламента),
  `qualify` (подагент-квалификатор: жёсткие фильтры кодом + LLM-вердикт по
  `skills/qualification.md`), `finalize_card` (карточка лида + файл-передача в `out/`).
- **Квалификация**: долг ≥ 350 000 ₽, регион прописки вне стоп-листа
  (Чечня, ДНР, ЛНР, Владимирская обл.).

## Запуск
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # при необходимости правь режим GigaChat
python main.py         # консольный канал (для теста без TG)
python main.py --tg    # Telegram-бот (нужен TELEGRAM_BOT_TOKEN)
```
Режим LLM: `GIGACHAT_MODE=mtls` (внутренний шлюз по сертификатам `certs/`)
или `token` (публичный GigaChat) — всё через `.env`.

## Тест-сценарии
- «Долг 200 тысяч» → вежливый отказ, карточка с end_result=not_suitable.
- «Прописан в Грозном» → отказ по региону.
- Идеальный лид (долг 800к, Татарстан) → вопросы, запись, карточка + .md-файл в `out/`.
- «Сколько стоит?» → без цифр, «считает юрист, без аванса».
- «А вы не мошенники?» → факты компании (с 2017, 2500+ дел, 1,05 млрд).
- «У меня ипотека» → скилл mortgage,Complex-флаг, запись с предупреждением юристу.
- «Вопрос про алименты» → отказ по домену.
