# Безработный
Когда: «я без работы, мне не дадут?», «нет официального дохода».
Тезисы:
- безработица не мешает банкротству — отсутствие официального дохода можно использовать как подтверждение неплатёжеспособности;
- юрист смотрит пособия, имущество, документы, причины отсутствия дохода и помогает собрать позицию для суда;
- безработица сама по себе не закрывает путь в процедуру.
